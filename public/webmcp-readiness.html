WebMCP 让网站把工具直接暴露给 AI agent——不是让 agent 截图点按钮，而是让它在请求时就调用你提供的能力。Vercel CEO 三次公开为它网站台。

"llms.txt is very much like the static representation of an agentic website. And the MCP now enables you to put an agent out into the internet." Guillermo Rauch, CEO Vercel — Sequoia 播客访谈

三个独立信号，同一个方向

① X 双层 Web 演化论（459 赞）：Rauch 判断 Web 正在分成两层——给人看的沉浸层，和给 agent 读的机器友好层。"markdown 格式和 MCP 协议的爆发式增长，就是这个趋势的信号。"

② Shopify 同台：DotDev 2026 炉边对话，Rauch 与 Shopify CEO 一致确认："MCP is a great success"——电商头部已在为 agent commerce 铺 WebMCP 路面。

③ Cloudflare 已入局：isitagentready.com（Cloudflare 官方检测工具）把 MCP Server Card、WebMCP 列为独立检查项。基础设施方、电商平台、检测方——三方都在。

WebMCP 就绪 = 三件事

1. 工具面存在：页面用 <script type="webmcp"> 或 registerTool() 注册工具。

2. 工具可理解：每个工具有真实的 name 和 description——agent 靠描述决定调不调你。只注册不描述 = 声明了但不可操作。

3. 工具面安全：描述字段是注入攻击的新入口（tool poisoning）。提示词注入、零宽字符、拼接混淆——注册了工具就要有人盯安全。

{ "name": "search_products",
  "description": "Search the catalog and return prices",
  "readOnlyHint": true }

English summary
WebMCP lets websites expose native tools to AI agents — a shift Vercel's CEO has publicly championed three separate times (the two-layer web thesis, the Sequoia podcast, and the DotDev 2026 fireside with Shopify). A ToolFront scan checks three things: does a WebMCP tool surface exist, is every tool operable (name + description), and is the surface secure against tool poisoning. Most top sites — including claude.com — have not implemented it yet. Early adopters get the score bump and the ecosystem presence.
